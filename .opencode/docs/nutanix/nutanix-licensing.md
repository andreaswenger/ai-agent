# Nutanix Licensing Guide
## Overview

This document provides an overview of Nutanix licensing models, software packages, and editions used to design, size, and price Nutanix-based solutions.

Primary reference:
- Nutanix Cloud Platform Software Options

---

# 1. Licensing Model Overview

Nutanix follows a **subscription-based licensing model** (modern model), replacing legacy “lifetime” licenses.

## Key Characteristics

- licensing is typically **per physical CPU core**
- applies across:
  - on-prem deployments
  - hybrid cloud environments
- licenses are:
  - portable across hardware
  - available as term subscriptions (e.g. 1–5 years)
