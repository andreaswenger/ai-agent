# What I do

I design and configure vector database layers for RAG systems, optimized for:

- high-performance similarity search
- scalable document embeddings
- enterprise-grade AI workloads

Focus area:
- Milvus-based architectures

---

# When to use me

Use this skill when:

- building scalable RAG systems
- selecting and configuring a vector database
- optimizing embedding storage and retrieval
- designing production-ready AI backends
- integrating Milvus with Kubernetes or AI platforms

---

# Inputs I expect

Ask for:

- embedding model (e.g. bge-base-en-v1.5)
- vector dimension
- data volume (number of documents / embeddings)
- query latency requirements
- deployment model (on-prem / Kubernetes / cloud)
- metadata filtering requirements
- update frequency (static vs streaming ingestion)
