# What I do

I design and generate complete RAG pipelines including:

- document ingestion and preprocessing
- chunking strategy definition
- embedding model selection
- vector database integration
- retrieval strategy
- LLM inference configuration
- evaluation and optimization

---

# When to use me

Use this skill when:

- building a chatbot over documents (PDFs, SharePoint, Files)
- creating enterprise knowledge assistants
- integrating AnythingLLM or custom RAG backends
- designing customer AI platforms
- validating RAG performance and accuracy
